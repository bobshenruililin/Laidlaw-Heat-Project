# Scientific-search constitution — Laidlaw heat–CHD/HF

**Status:** operational contract for this extract. Not a theory of science. Not a licence to mint a confirmatory primary.  
**Date:** 24 August 2026. **Mode:** Ship.

Bob’s production function, applied here:

```
R = f(compute, token budget, agent capability, search algorithm / harness, human mind)
```

The scarce design object is **scientific search**, not another overnight coefficient. A team that keeps a research agent, an evaluator, a knowledge base, scientific memory, a search tree, and experiment infrastructure will not reset when one paper ends. The next paper inherits the tree. Productivity compounds. That is the Matthew effect. It is also a failure mode if the thing that compounds is p-hacking.

This constitution exists so that **width × depth × shorter cycles** raise identification defensibility on this monthly extract, and so that token-maxxing / compute-maxxing cannot quietly become a hunt for a protected thermal finding.

## 1. What R is allowed to mean

On this project, a higher R is a more defensible identification article, a sharper named gap, a shorter honest cycle, and residue the next paper can load without re-deriving the killed paths.

R is **not**:

- a smaller p-value or a q that finally dips under 0.05,
- a confirmatory primary chosen after looking,
- a daily DLNM coefficient recovered from 132 monthly sums,
- a stroke, AMI/principal-diagnosis, cohort-incidence, heatwave-excess-death, or monetisation number,
- a Gate 3 freeze,
- a rewrite of Hogan’s weather paragraph,
- a rebuilt Stage 3 PDF.

If a search step would raise R only by minting one of those, the step is illegal even if it uses more compute or more tokens.

## 2. The five factors, bound to this repo

| Factor | What it is here | What it must not become |
|---|---|---|
| **Compute** | Re-runnable scripts, frozen tables, public-file grain checks, MDE from the existing ladder, the claim-ledger auditor | New real-data models that invent undelivered fields; retuning F1.2 after the failed calibration in order to admit a daily coefficient |
| **Token budget** | Parallel families, adversarial seats (Fable/Sol), lab rounds | Spending tokens to re-walk killed nodes, to fill Hogan/Roro/Bishai holes, or to polish a discovery headline |
| **Agent capability** | Named seats with jobs; isolation before an independent adversary is told the favoured thesis | One eloquent agent collapsing six families into a single attractive incomplete story |
| **Search / harness** | This directory + Playbook 06 + `scripts/60_scientific_search_cycle.py` | A dated `lab_run_*.md` that is forgotten when the chat ends |
| **Human mind** | Hogan weather lock, Roro stroke/person-time/ICD, Bishai Gate 3 / IRB, Bob paste and public voice | An agent “closing” those gates from defaults |

The human mind is multiplicative. Filling a human-owned hole with an agent guess makes reported R fake.

## 3. Width × depth × cycle

Three quantities, all required. Optimising one at the expense of the others is not scientific search.

**Width.** Number of *incompatible* approach families still alive, plus queued frontier proposals that are not human-blocked. Collapsing F01–F06 into “the identification paper” shrinks width. Playbook 05 already forbids that collapse. This constitution repeats it: width is diversity of scientific ideas, not diversity of wording.

**Depth.** Length of the longest path of *killed or closed lemmas that still constrain the next paper*. A dead end with a table contradiction or a forbidden-claim hit is depth. A dead end that exists only in a chat transcript is tourism. F1.2 daily recovery, confirmatory-primary promotion, public-file outcome substitution, and rescaling Goggins/Guo/Liu onto 1.022 / 1.073 are depth *because they are recorded as killed, with reasons*.

**Shorter cycles.** Time from “question” to “auditor-green residue or a named human-owned gap.” Cycles get shorter by loading memory, not by skipping the auditor. A cycle that invents a coefficient is not shorter; it is invalid.

The product we want:

```
search_power ≈ width × depth × (1 / cycle_length)
```

subject to the rails in §5. The evaluator scores that product. It does **not** score “found a significant heat effect.”

Playbook 05 remains the Jin-shaped *round* (families, adversary, dated `lab_run_*.md`). The harness fails a cycle if a killed or closed node disappears.

The next paper — stroke file if it arrives, a later daily extract if a new governed grain is delivered, a Hogan-locked HM/CM panel — **loads this tree first**. It does not re-discover that public HA throughput cannot replace monthly first-event CHD/HF, or that F1.2 failed, or that all twelve q > 0.19.

## 5. Rails (non-negotiable)

1. Gate 3 stays open. Lead recommendation remains Option A (no confirmatory primary) until the team freezes.
2. Hogan weather wording is verbatim, including “Meteorological data was obtained from the HKO.”
3. Stage 3 essay/poster PDFs follow the 22 August lock on `main`. Do not rebuild them from this system.
4. Do not invent HA rows, stroke coefficients, daily DLNM coefficients, still-at-risk person-time, AMI/principal-dx effects, heatwave excess deaths, or monetisation.
5. Contribution type remains **aggregation-identifiability + calibrated refusal**: an operational grain → estimand map for this extract, not a new estimator and not statistical priority over Basagaña–Ballester.
6. `estimand_policy` in `claim_ledger.yml` is a **string tripwire**, not a semantic estimand parser.
7. Daily lag at month grain is not declared *impossible* (that would contradict Basagaña–Ballester and this paper’s own hedges). It is *not recovered here* after failed simulation calibration. No real daily coefficient is admitted.
8. Excess-death mortality is a different estimand class. AMI/stroke/incidence are refused because required fields were not delivered. Do not lump those refusals.
9. Do not paste into Hogan’s shared live file. Do not email the Outlook thread. Do not start a parallel Word manuscript.
10. An independent adversary is not told the favoured identification thesis until after its first unaided read of the live file.

## 6. Evaluator (what “better search” scores)

See `eval_rubric.yml`. A node, cycle, or agent output scores up only if it:

- raises identification defensibility of the live article, or
- closes a named gap without invention, or
- leaves residue that shortens the next cycle, or
- keeps rails intact, or
- preserves family diversity.

A node that “finds” a thermal effect, promotes a core contrast to a primary, or fills a `blocked_human` hole **fails the cycle**, even if the claim-ledger auditor is green for unrelated reasons.

The machine claim-ledger auditor is a **hard gate**, not the whole evaluator. Green auditor + illegal success metric = failed cycle.

## 7. Token-maxxing and compute-maxxing, legal form

Legal:

- more incompatible families in parallel (width),
- more adversarial depth on a live family (Fable/Sol that can kill only with a table contradiction or a forbidden-claim hit),
- more re-runnable checks that do not require undelivered files,
- more memory written so the next cycle does not re-walk a dead end,
- more seats only after isolation rules are met.

Illegal:

- more specifications until one interval excludes 1,
- more tokens on a blocked_human family except readiness packets,
- more compute to reverse the F1.2 refusal,
- more prose restating “all q > 0.19” as if it were a new result,
- treating CNS *register* as a CNS *venue*.

## 8. Stop rule

A cycle may stop only when:

1. `python3 scripts/50_audit_live_claim_ledger.py` is green, or every red item has a named source-file contradiction,
2. the tree validator is green (`python3 scripts/60_scientific_search_cycle.py`),
3. every remaining hole on the frontier is `blocked_human` with an owner, or `queued` with a job that does not invent data,
4. no agent filled a hole by invention.

Partial progress is a named gap or a killed node with a reason. It is never a coefficient.

## 9. Originality bound for this system itself

This constitution is an operating manual for one governed extract. It does not claim a new theory of scientific discovery, a general AGI research lab, or priority over Jin’s Crouzeix institute, Basagaña–Ballester aggregated-outcome methods, or the lab’s own Playbook 05. What is intern-owned is narrower: a persistent search tree, memory, evaluator, and cycle harness that **do not reset**, scored on identification defensibility rather than on finding heat.
