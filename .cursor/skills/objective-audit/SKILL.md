# Objective audit (inherit; WORSE allowed)

## Trigger phrases

- `/objective-audit`
- “Objectively, is this better or worse?”
- “Pressure-test the Discussion insert.”

## Preconditions

- [ ] The shorter Hogan stop is the comparator unless Bob names another baseline.
- [ ] Kill list `analysis_plan/objective_audit/kill_list.yml` has been read.
- [ ] Gate 3 stays open. Models 2/3 are not fitted without governed panels.
- [ ] Named Fable 5 Max / Opus 5 Max / Sol 5.6 Max may fail to start. Do not wait on them.

## Execution

1. Run `python3 scripts/71_objective_audit_tripwires.py`. A red tripwire is a stop, not a prompt to invent matching prose.
2. Launch **inherit** `generalPurpose` auditors with explicit roles (claim–evidence; Hogan spare English; identification/policy routing). Do not require Max model slugs.
3. Each auditor must answer: BETTER / WORSE / MIXED against the comparator, and whether the insert should be kept, cut, or moved to an appendix table.
4. WORSE is a valid and expected verdict. Do not reverse a WORSE call to protect sunk-cost prose.
5. Write `reports/objective_audit_YYYY-MM-DD.md` with the table of seats and the parent synthesis.
6. If the parent synthesis is WORSE, cut the insert (or do not add it). Keep Table 2, Abstract, and Hogan HKO sentences unless a separate Ship names them.
7. Do not freeze Gate 3. Do not invent Model 2/3 coefficients. Do not reconstruct counts from Figure 1.

## Kill-list (minimum)

Live Discussion must not contain `can inform four`, `sits with official`, or `continued attention` as policy-support language. Must not claim `we evaluated VHWW` or `admissions averted`.

## Done when

- Tripwire script is green **or** every red item has a named file contradiction.
- A dated audit note exists.
- Remaining holes are human-owned (Hogan / Roro / Bishai / Bob).

## Claim boundaries

An audit is not a finding. A cut is not a Gate 3 freeze. Inherit role-labels are not the named Max models.
