# Temperature / exposure panel for Roro

Prepared 7 August 2026 in response to Roro’s request to share the completed temperature panel.

| File | Contents |
|---|---|
| `temperature_monthly_panel_2013_2023.csv` | HKO Headquarters monthly means and official extreme-day counts |
| `analysis_exposures_monthly_2013_2023.csv` | Analysis-ready exposures including lags, pollution, flu, COVID phase |

**Provenance:** REAL public Hong Kong Observatory / EPD / CHP-derived project layers. Not HA health data.

**Join key:** `month_id` (`YYYY-MM`), January 2013–December 2023 (132 months).
