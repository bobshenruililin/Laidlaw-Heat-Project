    The calibration that should change a sentence

    This is why Guo’s distinction between an official hot-night flag and hourly night-heat intensity is not a footnote. A threshold is a station object. Reanalysis does not inherit it for free. Apparent temperature on the same grid is a third object: humidity pushes humid cities past 28°C far more often than dry-bulb, and also past the station. It does not reconstruct HKO, and it is not a reason to paste reanalysis flags into the live paper.
