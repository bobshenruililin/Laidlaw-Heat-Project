# Playbook 06 — Compounding scientific search

## Trigger

Run when Bob (or an agent under an explicit `/playbook-06-scientific-search` command) wants the persistent scientific-search layer: production function, search tree, scientific memory, evaluator, and one cycle of the harness.

This playbook is the compounding layer on top of Playbook 05. A 05 lab round writes a dated `lab_run_*.md`. This playbook **must not reset** when that round, or this paper, ends.

Do **not** run this playbook as token-maxxing or compute-maxxing in search of a protected thermal finding.

## Preconditions

- [`knowledge/CONTEXT_BOOTSTRAP.md`](../../knowledge/CONTEXT_BOOTSTRAP.md) has been read.
- [`analysis_plan/scientific_search/CONSTITUTION.md`](../scientific_search/CONSTITUTION.md), [`search_tree.yml`](../scientific_search/search_tree.yml), [`memory.yml`](../scientific_search/memory.yml), and [`eval_rubric.yml`](../scientific_search/eval_rubric.yml) have been read.
- Gate 3 is **open**. This playbook does not close it.
- Hogan’s weather paragraph is not being rewritten.
- Programme Stage 3 PDFs stay byte-locked on `main`.

## Production function (bound)

```
R = f(compute, token budget, agent capability, search harness, human mind)
```

On this extract, R is identification defensibility × named gaps closed without invention × residue for the next cycle. It is not a smaller q-value.

Search power ≈ width × depth × (1 / cycle length), subject to the constitution rails. The harness reports a **proxy** (`width × depth × inheritable constraints`). That proxy is not a p-value and not a health finding.

## Steps

1. Read the constitution. If a step would raise R only by minting a confirmatory primary, a daily/stroke/AMI/excess-death/monetisation coefficient, a Gate 3 freeze, or a Hogan weather rewrite, stop.
2. Run `python3 scripts/60_scientific_search_cycle.py`. This loads the tree and memory, validates rails, and runs `python3 scripts/50_audit_live_claim_ledger.py` as a hard gate.
3. Optionally run `python3 scripts/test_60_scientific_search_cycle.py`.
4. Keep incompatible families alive (F01 identification, F02 multiplicity, F03 local daily history). Refresh F04/F05 only as human-owned readiness packets. Do not fill those holes.
5. Launch named critics (Fable, Sol) against the **search system** only after an independent adversary has had an unaided first read of the live file. They may kill a design choice only with a rails contradiction, a gameable metric, or a reset-after-paper failure.
6. Write residue into the tree, memory, and `analysis_plan/scientific_search/cycles/YYYY-MM-DD.md`. Do not start a parallel manuscript. Do not paste into Hogan’s live file.

## Done when

- A cycle note exists under `analysis_plan/scientific_search/cycles/`.
- The harness is green (or every red item is a named source-file contradiction).
- The claim-ledger auditor has been run.
- Remaining holes are `blocked_human` with owners.
- Hogan weather is unchanged.
- Stage 3 PDF and A0 poster were not rebuilt.
- The tree still contains killed nodes from prior papers/rounds (no reset).

## Failure modes

- Treating token-maxxing or compute-maxxing as a hunt for a Nature finding or a confirmatory primary.
- Scoring “found a significant heat effect.”
- Resetting `search_tree.yml` / `memory.yml` at paper end.
- Filling Hogan / Roro / Bishai / Bob gates from defaults.
- Declaring daily lag impossible at month grain (contradicts Basagaña–Ballester). Daily recovery **failed here** after F1.2 calibration; no real daily coefficient is admitted.
- Lumping AMI/stroke/incidence (missing fields) with heatwave excess-death (different estimand class).
- Treating `estimand_policy` as a semantic parser rather than a string tripwire.
- Claiming this constitution as a new theory of science or priority over Playbook 05 / Basagaña–Ballester.
- Rebuilding Stage 3 PDFs.
