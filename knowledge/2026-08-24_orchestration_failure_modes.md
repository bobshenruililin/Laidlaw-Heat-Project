## Countermeasures (enforce immediately)

1. **Bottleneck card (first 15 lines of any delegated task).** Exactly one critical blocker. Owner. Agent-cannot-do. Forbidden substitutes. Example for this project now: *Blocker = paste into Hogan live file + Bishai Email A. Agent cannot send mail or paste. Forbidden substitute = another PDF rebuild, another SATISFIED table, another SHA theatre.*
2. **Hardest-first gate.** No copy-edit, no hash freeze, no INDEX row until the bottleneck card is either done or explicitly blocked on a named human. Hygiene balloons (H21, KW7, KW8) are batch-2.
3. **Zoom-out checkpoint** every 8–10 tool batches or 15 minutes of wall clock, whichever first. Required output: one sentence of the user objective; last five actions; whether they moved the bottleneck. If no, abort the rabbit hole.
4. **Comment stack, not comment list.** Hogan/Jingjing input is parsed into identification / register / process / hygiene before any rewrite. SATISFIED is illegal for identification items that are only specified, not fitted. KW14 must read `SPECIFIED; UNFITTED`, never a clean tick.
5. **Stateless rewrite forks.** When Bob says rebuild/replace, the new brief may cite the old lock once in a changelog, then must not re-argue it. New SHA file replaces the old lock; tests that freeze superseded hashes are deleted on the same commit.
6. **Track isolation.** Journal live-manuscript branch and Stage 3 programme branch do not share a working tree for “quick hash patches.” End the session on the track the user asked about.
7. **Output schema for orchestrator summaries.** Always: (a) bottleneck status, (b) what was actually sent vs drafted, (c) human-only leftover, (d) what was *not* done. Ban leading with SHA tables.
