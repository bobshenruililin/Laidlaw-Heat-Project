## What it is

A mycelium of **exactly twelve** Model 1 fits. Hyphae follow the pointer (the expensive trick). Fruiting probability follows Benjamini–Hochberg *q*, so a confirmatory mushroom does not fruit. Click **Publish 1.022** or **Publish 1.073** and paper airplanes knock the cap down. The HUD still shows *q* = 0.192 on the same panel.

Coupled systems, each a lemma:

- Weather field: official hot nights increased; official cold days persisted. Caption *weather.*
- Depletion pool: 156,156 / 29,681 events as REAL counts; sprites are 1:100. Caption *people leave the pool.*
- Equation (1): offset → month dummies → 4-df spline → one *X*. *e^β* is a monthly count ratio.
- Daily engine: 500-replicate calibration fails. No real daily coefficient.
- 2018 ruler: 26 official hot nights, zero days in ≥5-night spells.
