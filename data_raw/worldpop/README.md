# WorldPop Hong Kong 2020 (public)

**Provenance:** WorldPop unconstrained 1 km ASCII, 2020.
Source: `https://data.worldpop.org/GIS/Population/Global_2000_2020/2020/0_ASCII_gridded_XYZ/HKG_ppp_1km_2020_ASCII_gridded_XYZ.zip`

`ppp_HKG_2020_1km_Aggregated.csv` columns: `X` (lon), `Y` (lat), `Z` (people per ~1 km cell).

Used only to population-weight ERA5-Land 0.1° *exposure* nights. Not a health surface. Not a C&SD census file. Not committed as a GeoTIFF (rebuildable; ~0.7 MB).
